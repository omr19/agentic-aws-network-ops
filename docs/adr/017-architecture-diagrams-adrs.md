# ADR 017 — Architecture Diagrams and ADRs

## Status
Accepted

## Decision
Maintain numbered ADRs and five professional AWS diagrams. Store editable draw.io
sources plus SVG or PNG exports in `docs/diagrams/` and use official AWS icons.

## Consequences
ADRs explain why, diagrams explain how, and governance files record status. Diagrams
start in Phase 2, evolve at milestones, and finalize against implementation in Phase 12.
